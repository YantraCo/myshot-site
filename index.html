How we build

Four commitments
01

Your data stays yours

MyShot uploads to the Google Drive account you already own. Files sit under your storage quota, stay owned by you, and never pass through infrastructure of ours — because there isn't any. If every service we run vanished tomorrow, the app would keep working.

02

The narrowest permission

We ask for the least access that does the job. MyShot requests Google's drive.file scope, which can only ever see files the app itself created. We verified this against a real account: listing files returned zero results for everything MyShot hadn't made.

03

No telemetry, at all

No analytics, no crash reporting, no usage counters, no advertising identifiers. Nothing phones home, including in paid versions. We learn how the software behaves by using it every day ourselves.

04

Small and finished

Three tools that work beat one platform that almost does. Each product is scoped to a job you can describe in a sentence, then built until it's genuinely done rather than perpetually in beta.
